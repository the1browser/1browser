# Get fingerprint for profile id

`GET /v1/profile/{id}/fingerprint`

Operation ID: `ProfileController_getProfileFingerprint_v1`

Authentication: `Bearer <token>` required

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `id` | path | yes | `string` | Profile id |

## Request body

No request body.

- `200`:
